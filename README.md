# C-Language-Learning

记录我的 C 语言学习过程、代码练习和阶段性成果。

目前正在学习 Git 与 GitHub 的基本使用，仓库先建立基础结构，后续逐步加入自己编写和理解的代码。

## 目录

| 目录 | 用途 |
| --- | --- |
| Basic | 基础语法练习 |
| Functions | 函数练习 |
| Arrays | 数组练习 |
| Pointers | 指针练习 |
| Structures | 结构体练习 |
| Projects | 小型综合项目 |

各目录暂未添加练习代码。`.gitkeep` 是用于保留空目录的占位文件，因为 Git 不记录空目录。

## 使用环境

- Windows
- GCC（MinGW-w64）8.1.0
- VS Code

加入具体程序后，将补充对应的编译、运行方法和学习记录。
